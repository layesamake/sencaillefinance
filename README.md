# SENCAILLE Finance

Application web mobile-first 100% en ligne pour gérer les recettes, dépenses, paiements, crédits et rapports mensuels de la ferme SENCAILLE.

## Stack Technique

- **Framework :** Next.js (App Router)
- **Langage :** TypeScript
- **Style :** Tailwind CSS
- **Base de données & Auth :** Supabase (PostgreSQL)
- **Déploiement :** Vercel

## Lancement en développement

1. Renommer `.env.example` en `.env.local` et remplir les variables Supabase.
2. Installer les dépendances : `npm install`
3. Lancer le serveur de développement : `npm run dev`

L'application est accessible sur [http://localhost:3000](http://localhost:3000).
